# Reactive

Reactive is a tabletop roleplaying system built around a common resolution structure that can be used for combat, social scenes, performances, and other meaningful conflicts.

## Repository layout

- `apps/dice_roller/` — dice rolling and roll-resolution application.
- `apps/character_sheet/` — digital character sheet application.
- `rules/` — system rules and design notes.
- `flowcharts/` — player-facing and GM-facing diagrams.
- `examples/` — worked examples and edge cases.
